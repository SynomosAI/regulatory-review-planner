# 合规审查法律来源与引用规则

## 来源优先级

1. 当前任务中用户上传、粘贴或选定的制度草稿、附件、上级制度、模板、历史版本和既有审查结果；
2. 本 Skill 的已确认审查规则和审查项体系；
3. 本次实际返回的法宝版法律法规或司法案例 MCP 结果；
4. 本次实际读取的官方公开来源；
5. 模型知识，仅可作为待核验提示。

## 来源标签

- `[用户提供材料]`：本次实际读取的用户上传、粘贴或选定的制度草稿、附件、模板、上级制度或历史审查资料。
- `[审查规则]`：本 Skill 中已固化的审查项、严重程度规则或输出规则。
- `[法宝 MCP 检索]`：本次实际返回且用于法规、法条或案例判断的 MCP 来源。
- `[官方来源]`：本次实际读取的官方公开材料。
- `[主体信息待人工核验]`：主体、集团、登记、处罚或涉诉信息未由当前法宝版 MCP 核验。
- `[模型知识—需核验]`：未被上述来源核验的法律命题或风险判断。
- `[法条未调取—需核验]`：可能相关但本次未取得原文的法条。
- `[案例未调取—需核验]`：可能相关但本次未取得可核验案例信息。
- `[上级制度未取得—需核验]`：需要对照上级制度但本次未取得原文。
- `[内部材料待补充]`：需要补充企业内部文件或岗位事实后，才能形成完整结论。

不得以模型记忆、MCP 名称或历史结果冒充已核验法律依据。涉及现行法律、法规时效、处罚权限、个人信息保护、公平竞争、劳动者权益、监管要求或司法趋势时，未检索不得作确定性表述；来源冲突时披露冲突并转人工法务复核。
